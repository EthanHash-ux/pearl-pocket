# 掌珠钱包：应用方向

0.6.0 已有手机签名钱包、多个只读地址、带金额收款二维码、分享 PNG、分页交易历史、本机备注、CSV、矿工监控和通知。以下方向可以在这些能力上继续做产品，不把计划功能当成现有能力。

## 1. 小商家收款台：最适合作为下一步

现在可用：填写 PRL 金额 → 分享二维码图片 → 客户付款 → 查看交易 ID 与确认数 → 在本机备注订单号 → 导出 CSV 对账。观察地址可用于店员查看，店员手机不持有商家私钥。

下一版可增加独立“收款台”：本机订单号、商品、应收金额、生成时间、收款交易绑定、待支付 / 待确认 / 已核对列表、按日汇总。订单号必须绑定实际链上交易；只有收到可验证的交易并满足商家选定的确认数，才能标记已核对。付款截图或矿池支付记录不能证明商家已收款。

固定单地址无法仅按金额自动唯一匹配同额订单，故先做人工绑定交易 ID。更完善的自动匹配需要新增可跟踪的派生收款地址、扫描与找零管理，不能只改界面。后台轮询也不能保证秒级到账提醒。

## 2. 矿工收入账本：现有功能可以直接开始

现在可用：保存不同矿工的公开收款地址，在 HeroMiners 查询普通模式工作器的提交时间、可支付余额、待成熟奖励、累计支付和最近付款；在链上历史备注设备或租赁用途，再导出 CSV。

下一步：多矿池分别核验接口、设备电费档案、月度净收益报表、工作器长时间无提交提醒。矿池累计支付与链上确认收入分开记；以链上交易去重，避免矿池付款和钱包入账重复累计。个人算力接口只返回计分速率时，保留原始单位，不假造 H/s。

## 3. 家庭或团队资产看板

现在可用：加入多个公开地址，逐个查看余额和记录；观察模式拒绝转账。

下一步：分组、合计资产、本机名称、导出仅包含公开配置的备份。不同币种分开计数；价格过期时显示时间。桌面或网页看板只接收这些公开地址，不接收手机钱包助记词。多人共同花费资金需要独立的多签协议设计，观察地址不等于多人签名钱包。

## 4. 自由职业收款与个人记账

现在可用：分享带金额二维码、备注项目或客户名称、CSV 对账。

下一步：项目账本、收支分类、月度报表、按交易时间记录参考汇率。历史法币收入应使用当时汇率，并记录来源；不能把今天的价格当成过去的收入。税务导出规则需要单独按所在地设计。

## 5. 社区捐赠与公开透明页

现在可用：公开一个收款地址，其他人用观察模式检查收款记录。

下一步：生成公开收款卡片、活动目标、仅展示链上已确认收入的活动页。公开页不得加入密钥或钱包密码。款项用途属于组织的线下记录，需要说明并链接相应凭证。

## 建议开发顺序

先做“小商家收款台 + 本机订单与交易绑定”，再做“矿工月度账本”，最后做“仅公开数据的网页看板”。这三条方向可以共用备注、交易历史和导出能力。

交易所买卖、自动理财、跨链兑换需要经过核验的 Pearl 接口和另行设计的授权流程；本版不将它们包装成可用入口。

参考：[Pearl 官方项目](https://github.com/pearl-research-labs/pearl)、[Pearl Hub 官方 App Store 介绍](https://apps.apple.com/us/app/pearl-hub-prl-wallet-pools/id6777132941)、[HeroMiners Pearl 站点](https://pearl.herominers.com/)。参考的是需求与使用流程，掌珠钱包采用自己的 Android 实现。
