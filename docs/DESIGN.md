# Pearl Pocket 0.5.0 界面与功能设计

本轮直接修改 Android 原生界面，交付可安装 APK。设计以钱包的常用操作为中心：首页看余额与币价，一步进入收发；行情看曲线与提醒；矿业看指标与成本；设置管理隐私和备份。

## 视觉系统

- 珍珠白背景，深蓝资产卡，薄荷绿作为操作与选中状态，负涨跌使用红色。
- 统一圆角、内外间距、文字层次、输入框和对话框。底部五个入口使用手绘矢量线条图标和中文标签。
- 首页缩短地址并保留复制与备份入口。发送审核和收款页仍显示完整地址。
- 行情图增加价格刻度、末端报价标记与填充区域，保留触摸查看和数据来源时间。
- 挖矿页用六个指标单元展示公开矿池数据，收益计算与统计分开呈现。
- 助记词输入与备份使用三列编号网格；恢复词数可直接切换。
- 保留原生滚动、大字设置和无障碍语义；常用主按钮和输入框高度至少 48 dp。长页面允许滚动，不把全部工具挤进首屏。

## 本轮增加的实用功能

| 功能 | 行为 | 边界 |
| --- | --- | --- |
| 余额隐藏 | 首页眼睛按钮或设置开关；重启保留选择 | 钱包余额、法币金额、未确认金额和交易金额一起隐藏；无障碍朗读同步遮盖；转账审核仍显示实际金额 |
| 交易筛选 | 记录页切换全部、接收、发送 | 基于本地址净变化筛选最近十笔；不是全历史检索 |
| 联系人搜索 | 按名称或完整地址筛选本机联系人 | 名称不区分大小写；选择时仍使用已校验的完整主网地址 |
| 提醒重新启用 | 已触发提醒经确认后重新等待下一次新报价 | 保留原目标与方向，再触发一次；新报价已经达到目标时可能立即通知 |

## 界面验证与截图

截图来自实际 Android 15 模拟器，使用公开的零熵 BIP39 测试向量钱包。四个公开页面的 PNG 随 Release 一起提供，界面行情是实际公开请求的结果；截图数值随拍摄时间变化。

`DesignCaptureTest` 只存在于测试 APK，默认跳过。显式启用时要求模拟器和已知公开向量钱包，仅由仪器临时取消公开页面的截图保护，结束时恢复。发布 APK 始终启用 `FLAG_SECURE`，没有截图例外入口；助记词和密码页不参与截图。

自动验证覆盖恢复和备份、联系人选择、收款二维码、行情、提醒与收益操作，并增加余额隐藏的重启保留和无障碍遮盖测试。真机相机与不同厂商系统仍需单独验证。

## 下一步建议

1. **只读观察钱包**：添加公开地址即可看资产、交易和矿工收益。适合先扩展账户体验，不需要导入私钥；必须明确展示只读状态。
2. **矿工与工作器监控**：保存用户主动填写的公开矿池地址，显示支付记录、算力变化和离线状态。需要先核对各矿池接口与单位。
3. **联系人导入导出、收款二维码图片分享**：通过系统文件与分享面板，减少换机和收款时的重复输入；导入逐条校验地址。
4. **价格提醒编辑与更多图表周期**：保留新鲜度检查和一次性去重规则，明确后台任务会受系统调度影响。
5. **多独立钱包切换**：属于存储和签名流程改造，必须隔离各钱包密文、备份状态、UTXO 和待确认交易后再推出。

完整 Oyster XMSS/P2MR 恢复与签名需要专项协议开发，不作为界面功能开关直接加入。本轮不扩大已有钱包内核的协议能力。
