# Pearl Pocket 0.9.0 · 独立多钱包

掌珠钱包以收发和管理 Pearl 资产为主线。本版可以在同一台手机创建、导入、重命名与切换最多 10 个独立钱包，用于日常付款、储蓄和收款。首页的钱包选择入口或设置中的「管理手机钱包」可以打开列表。

每个钱包分别保存加密密钥、备份状态和待发送交易。创建或导入失败、取消以及重复导入不会覆盖原钱包；切换不会移动资金。转账确认显示付款钱包和完整地址。收款通知查询所有手机钱包与观察地址，点击通知可选择对应钱包。

0.8.0 及更早版本的钱包原地保留，不迁移文件、不改变原密码或设备密钥。下载安装新版时保留应用数据，逐个保管助记词。完整行为与存储说明见仓库的 `docs/MULTI_WALLETS.md`，后续开发路线见 `docs/APP_SCENARIOS.md`。

本版继续提供原有行情、历史、只读观察、矿池和跨链工具。钱包仍使用英文 BIP39、空附加口令与固定单地址 BIP86；未增加 XMSS 签名、硬件钱包或自动交易。

仓库公开。下方 Assets 提供非调试签名 APK、源码、校验和及验证报告。最低 Android 8.0，支持 ARM64 与 x86_64。验证详情以随包 `TEST_REPORT.md` 和 `verification.json` 为准。此版本仍为未经独立安全审计的开发测试版。
