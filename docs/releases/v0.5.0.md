# Pearl Pocket 0.5.0 · 掌珠钱包

这一版重做原生 Android 的钱包首页、行情、矿业、交易记录与设置：珍珠白背景、深蓝资产卡、薄荷绿操作、统一线条图标与圆角表单。首页突出余额与收发，行情图增加价格刻度和最新报价标记，矿池改为六个可对照指标，助记词输入与备份以编号网格呈现。

新增余额隐藏及其无障碍遮盖、最近记录的收发筛选、联系人名称 / 地址搜索、已触发价格提醒重新启用。隐藏金额后转账审核仍显示真实金额，方便核对。

安装 `pearl-wallet-android-0.5.0.apk`，最低 Android 8.0，支持 ARM64 与 x86_64，关闭 debuggable，沿用开发证书，可覆盖升级 0.4.0。源码与本发布提交逐字节一致，包含 Java 界面、Go/JNI 钱包内核和测试；签名私钥不进入仓库与附件。

附件中的四张界面截图来自实际 Android 15 模拟器与公开测试向量钱包，不含真实资金或私钥。余额为公开测试钱包的余额，行情与矿池数值取自当时公开请求。

验证包含 32 项 Java 单元测试、11 项常规 Android 仪器测试、1 项 0.4.0 → 0.5.0 发布版覆盖升级测试，Android lint 无问题；另执行公开页面截图检查。Go/JNI 原生库与 0.4.0 逐字节相同，沿用该版本通过的 race 测试与官方 simnet 转账证明，当前版本重新验证 JNI 与签名相关仪器测试。具体证据与限制见 `TEST_REPORT.md`、`verification.json`、`SHA256SUMS`。

这是开发测试版本，尚未经独立安全审计或主网实币转账验证。仍使用固定 BIP86 单地址钱包，支持英文 BIP39 12 / 15 / 18 / 21 / 24 词、空附加口令，不支持完整 Oyster XMSS 恢复。后台价格提醒为系统周期检查，不是即时服务器推送。
