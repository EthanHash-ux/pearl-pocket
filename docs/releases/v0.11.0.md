# Pearl Pocket 0.11.0

钱包首页新增「买卖 PRL」，接入 pearl-trade 的原生 PRL / Arbitrum USDC 现货订单簿。支持绑定平台账户的原生 PRL 充值、本机签署保护限价买卖单、部分成交查询和撤单，以及将平台 USDC 或 PRL 提现到本钱包。

每次充值、订单和提现分别审核并验证手机与钱包密码；签名在本机完成。新请求签名在提交前按钱包保存；网络超时保留原请求并阻止重复签署，需先核对平台记录。费率与交易单位取自对应市场，金额不经浮点运算或静默截断。

卖币流程为「充值 → 成交 → 申请提现 → 链上核验」。平台交易余额由运营方托管，提现需其处理。平台订单接收、成交或 `confirmed` 状态不会直接当作 USDC 回到钱包；本机核对固定 Arbitrum USDC Transfer 日志、净额、收款人、区块与 L1 safe / finalized 状态。

买单使用已有平台 USDC；Arbitrum USDC 充值与普通转出当前仍需外部兼容钱包。没有自动交易、自动提现、WalletConnect 或跨链原子兑换。使用范围与来源见 docs/SPOT_TRADING.md。

继续作为开发测试 prerelease。验证涵盖独立 Ethers 签名向量、Java / Go / JNI、Android 操作流程、模拟传输和主网只读历史提现；没有进行主网实币充值、真实订单提交、提现申请、真机验证或独立安全审计。详细证据见 TEST_REPORT.md 与 verification.json。
