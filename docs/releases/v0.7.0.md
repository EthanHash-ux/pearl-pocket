# Pearl Pocket 0.7.0 · 掌珠钱包

新增“行情 → 跨链与价差工作台”：查询 PearlBridge PRL/WPRL 真实桥费、净额、暂停、额度、快 / 慢通道；PRL 转入使用手机钱包原有内核签名，WPRL 赎回通过外部 Ethereum 钱包。保存公开 Ethereum 地址，查询 WPRL / ETH 余额，以及按原链交易 ID 查看跨链进度。

接入 Lighter 固定 PRL 永续市场 4097 的盘口、标记 / 指数价和最近已结算小时资金费，以及固定 Uniswap V3 WPRL/USDT 池的指定数量报价。双向现货路线以真实盘口和桥净额试算费用；现货加永续空头试算包含平仓价差、正负资金费、账户费率、额外成本和显式 USDC/USDT 汇率假设。深度不足不外推，过期、暂停、错误代币 / 合约、充值地址变化会阻止继续。

桥充值地址使用本机首次记录固定，每次要求用户在桥网站核对完整地址。PRL 规划和设备认证前重新核对桥条款；核对后两分钟内签名，网络请求发生在种子解密之前。保留广播前存储、超时后相同原文重发及新发送阻止机制。新增 EIP-55 地址校验，没有 Ethereum 种子派生或导入。

修复行情切换至仅美元 / 人民币备用报价时，价格组件缺少 USDT 导致的崩溃；保留原 USDT 缓存。

安装 `pearl-wallet-android-0.7.0.apk`，最低 Android 8.0，ARM64 / x86_64，沿用开发证书。附件包含完整 Java / Go / JNI 源码、原生截图、测试报告、隔离 simnet 转账证明和 SHA256。
