# Pearl Pocket 0.8.0 · 掌珠钱包

新增「PearlFortune 我的矿工」原生页面：保存公开挖矿收款地址，查看 1 / 8 / 24 小时矿池估算算力、接受率、接受 / 拒绝贡献、在线连接及 worker 自报算力、GPU 数量和更新时间。可直接打开对应地址的 PearlFortune 完整网页，查看结算、账本、收益计算和 NOCK 合并挖矿。

新增安卓桌面「算力与价格」组件：同时显示 BigONE PRL/USDT 行情、24 小时涨跌及 PearlFortune 算力，支持矿池总览或个人地址、多个组件独立配置、点击进入矿工详情与手动刷新。后台每 15 分钟尝试更新，实际执行时间受安卓系统限制；前台行情也同步到组件。

价格、算力、连接分别标注更新时间和缓存；刷新失败保留旧数据。矿池估算与矿机自报分别显示，保留 H/s / MAC/s 各自单位，不完整数据为未知。切换矿工后，旧查询不能覆盖新配置。只查询公开数据，无需解锁钱包。

保留独立手机钱包、BIP39 恢复、原生 PRL 签名和收发、HeroMiners 监控、价格组件及跨链与价差工作台。仍为开发测试预发布版本。

安装 `pearl-wallet-android-0.8.0.apk`，最低 Android 8.0，ARM64 / x86_64，沿用现有签名证书。附件包括完整 Java / Go / JNI 源码、真实安卓页面及桌面截图、测试报告和 SHA256。

本仓库公开，可直接在本版 Assets 中下载安装包；可覆盖升级 0.7.0，保留已有钱包和备份状态。
