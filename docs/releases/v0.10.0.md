# Pearl Pocket 0.10.0

钱包首页新增 DeFi 借贷流动性入口，支持 Ethereum 主网 Aave V3 USDC 的明确金额授权、存款、含利息仓位与浮动 APR 查询，以及无借款仓位的赎回。Ethereum 地址从每个独立钱包的同一份助记词按标准 BIP44 路径派生；原有 Pearl 地址与密文保留。

每笔授权、存款和赎回分别预览金额、合约和最高 ETH 网络费，验证手机解锁与钱包密码后本机签名。固定协议与资产、拒绝无限授权、模拟失败阻止签名。广播前保存原交易，超时与重启后查询或重发相同签名和 nonce；成功或回滚需至少 3 个区块及规范区块哈希检查。

此版本的 LP 功能指借贷单资产流动性，不包含 Uniswap LP、借款、杠杆或自动操作。有借款的地址需在 Aave 管理抵押与赎回。Ethereum 签名仅支持此借贷流程，普通 ETH / USDC 转账暂需在兼容钱包恢复同一助记词后管理。需要 Ethereum 主网 USDC 和 ETH；没有声称 PRL / WPRL 可存入 Aave。

验证结果、主网只读核验与模拟链测试见附件 TEST_REPORT.md 和 verification.json。模拟链使用模拟协议合约；没有使用主网实币或完成独立安全审计。继续作为开发测试 prerelease 发布。使用范围见仓库 docs/DEFI.md。
