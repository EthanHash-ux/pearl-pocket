# Pearl Pocket 0.4.0 · 掌珠钱包

本次同时完善钱包收发、行情跟踪和矿业工具，参考 Pearl Hub 的任务组织方式独立实现功能。

- 本机地址簿：新增、编辑、删除联系人，发送时直接选择并核对完整地址。
- 相机或本机图片识别收款二维码；只预填地址和金额，后续仍需预览、确认与本机签名。
- 默认纯地址收款二维码，以及可选带金额的 Pearl Pocket 收款请求。自定义请求格式不代表 Oyster 兼容标准。
- 本机 PRL/USDT 目标价提醒：高于 / 低于目标后通知一次，拒绝过期行情，前后台并发检查不重复触发。
- HeroMiners 公开矿池统计与 CNY 收益情景计算，含电费、矿池费、租金、30/90 天净收益和盈亏平衡币价。
- 原生交易详情、交易 ID 复制和源码入口，应用名称更新为掌珠钱包。

价格提醒前台随行情检查；后台由 Android 约每 15 分钟调度，省电和网络可能延迟，不提供服务器即时推送。相机和通知权限仅在使用对应功能时申请。矿池数据只表示公开统计，不在手机上挖矿；收益计算基于用户输入，不预测未来产出。

沿用原有 BIP39 英文 12/15/18/21/24 词导入、本机 Go/JNI 签名内核、Android Keystore 加密、签名前设备验证及钱包密码、原签名交易持久化与重发。签名协议路径与上游固定版本没有改变。

这是开发测试预发布版，尚未完成安卓真机测试、主网实币转账或独立安全审计。准确验证记录、APK 签名及 SHA256 见附件。源码包与发布提交一致，不包含 APK 私有签名证书、SDK、生成库或官方上游仓库副本。最低 Android 8.0，ARM64 / x86_64，16 KB 页对齐。
