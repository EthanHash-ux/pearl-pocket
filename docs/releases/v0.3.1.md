# Pearl Android Wallet 0.3.1

Pearl 主网手机独立钱包开发测试版，最低 Android 8.0，支持 ARM64 手机和 x86_64 模拟器。本项目独立开发，非 Pearl Research Labs 官方钱包发行版。

## 本版功能

- BIP39 英文助记词导入补齐 12、15、18、21、24 个词；可选择词数、整段粘贴、自动识别，并在手机本地检查拼写和校验和。
- 恢复流程依次核对完整地址、验证手机锁屏、设置新的钱包密码；新建钱包仍生成 24 个英文助记词。
- 本地 Go/JNI 内核负责地址派生、交易构建、Schnorr 签名和官方 Pearl 脚本引擎校验。
- 接收地址与二维码、余额与交易记录、发送审核与手续费、待确认交易查询或重发。
- BigONE PRL/USDT 实时行情及历史价格曲线；可选择 USDT、美元或人民币计价。

## 下载

- `pearl-wallet-android-0.3.1.apk`：已签名、关闭调试权限的安卓安装包。
- `pearl-wallet-android-source.zip`：本应用完整 Java/Go/JNI 源码与构建、测试、发布脚本。
- `SHA256SUMS`：下载文件的 SHA-256 校验值。
- `TEST_REPORT.md`、`verification.json`、`simnet-transfer.json`、`apk-signature.txt`：验证结果与公开 APK 证书信息。

GitHub 自动提供的 Source code 压缩包对应本次标签。源码构建需要按 README 获取固定提交的官方 Pearl 仓库；安装包的私有签名密钥不公开。

## 验证

11 项 Go 测试及 16 个子测试（race detector）、21 项 Java 单元测试、7 项 Android 15 模拟器仪器测试通过，Android lint 为 0 项问题。五种词数均完成导入、地址重建和签名验证；新增 15/18/21 词在安卓界面完成恢复、加密保存与重新解锁。隔离官方 simnet 已验证节点接收、出块确认与收款输出，未使用主网资金。

## 恢复范围

当前仅支持 BIP39 英文词库与空附加口令，固定无 XMSS 脚本树地址路径 `m/86'/808276'/0'/0/0`；尚未实现完整 Oyster 账户扫描、XMSS 状态恢复、旧版十六进制种子导入或非空 BIP39 附加口令。没有进行安卓真机测试、主网实币转账或独立安全审计。
