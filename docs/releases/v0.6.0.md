# Pearl Pocket 0.6.0 · 掌珠钱包

增加 20 个只读观察地址、分页交易历史、当前页搜索与本机备注、CSV 导出（全历史最多 5000 笔）、带金额收款二维码图片分享。观察模式查询公开地址，拒绝发送，不改变本机签名钱包。

发送页增加“发送全部余额”：原生内核从已确认成熟 UTXO 计算精确费用，生成一个收款输出、不找零，仍逐次要求设备验证与钱包密码。新增 HeroMiners 普通模式个人矿工监控，显示工作器提交时间、可支付 / 待成熟 / 已支付奖励和付款记录。接口的个人计分速率保留原始单位，不误标为 H/s。

新增深色主题、30 天价格图、价格提醒编辑与相对报价涨跌幅提醒、可手动刷新的 Android 桌面价格小组件，以及可选收款 / 首次确认通知。后台收款与价格提醒约 15 分钟周期检查，组件约 30 分钟；系统可能延迟，界面标注接收时间。首次收款检查建立基线，不补发历史通知，大量交易可能漏检。

安装 `pearl-wallet-android-0.6.0.apk`，最低 Android 8.0，ARM64 / x86_64，沿用开发证书，可覆盖升级 0.5.0。附件包含同提交完整 Java / Go / JNI 源码、实际安卓浅色与深色截图、测试报告、官方隔离 simnet 普通与全部余额转账证明、签名和 SHA256 校验和。

这是开发测试版本，尚未经独立安全审计、真机兼容性或主网实币转账验证。支持英文 BIP39 12 / 15 / 18 / 21 / 24 词、空附加口令、固定单地址 BIP86；尚不支持完整 Oyster XMSS 恢复、多签或多私钥钱包。全历史导出进行完整性检查，公开查询服务不提供原子快照。
