# Pearl Pocket 0.12.0 · USDT 购买入口与 PRL 推理服务

首页新增「用 USDT 购买 PRL」：查看参考报价、打开 BigONE 对应 PRL/USDT 现货页面、复制当前钱包的 Pearl 主网提现地址。实际订单在 BigONE 账户完成，尚未实现钱包内直接签署该交易所订单。现有 pearl-trade PRL/USDC 现货功能保留；USDT 与 USDC 分别显示。

新增独立「AI 推理服务」：绑定受信任商家、查看 PRL 单次模型价格、购买调用次数、审核并本机签署 PRL 账单、查询到账开通额度、查看调用记录、试用文本 API。每钱包独立加密保存商家 API Key。付款仍要求系统验证和钱包密码；不明调用阻止重复发起。

仓库同时提供可运行的商家服务与离线收款恢复工具。商家为每张账单分配独立地址，等待 6 个确认，验证原始交易、精确金额、有效时间和规范区块。同一付款只能开通一次；推理调用使用持久预留和请求 ID，不自动重复执行，提供商家核对工具。

**没有预配置或部署公共 PRL 商家；没有主网实币或收费模型验证。** 正式开放需配置自己的域名、独立收款 xpub、模型价格、上游 Key 与注册邀请码。Pearl 官方 AI 目前通过美元余额 / Stripe 收费；本版本实现独立商家的 PRL 服务交易协议，不是官方 PRL 充值接口。首版为受限容量、单进程试用服务，尚无完整商家平台和运营后台。详见 [部署与 API 说明](https://github.com/EthanHash-ux/pearl-pocket/blob/v0.12.0/docs/AI_INFERENCE.md)。

开发测试 APK，使用原有证书，可覆盖升级。验证证据和当前源码随 release 提供；不是经过独立审计的正式商业版本。
